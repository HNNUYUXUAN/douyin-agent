# 维护、验收与发布

[English](../en/maintenance.md) · [索引](../index.json)

## 适用意图

维护双语文档、实现和公开素材，验证改动并准备普通目录发布及安装升级。

## 前置条件

已明确本次修改/发布授权，能访问实际源码和对应测试证据；开始前遵循仓库 AGENTS.md。

## 最少输入

改动范围、目标版本/提交、受影响能力与证据；如涉及公开素材，需其可公开性和来源说明。

## 操作步骤

维护者先读 [AGENTS.md](../../../AGENTS.md)、涉及的运行脚本和中英文指南。README 面向使用者，操作细节放本目录；机器入口 `index.json` 与 `llms.txt` 必须和实际文件及命令保持一致。

修改安装/首次引导时，覆盖首次与重复安装、现有文件哈希冲突、配置保留、缺 Conda/FFmpeg、只读预检、宿主记录回写与重启后路径复用。修改任务处理时运行 `PYTHON scripts/test_da.py`，必要时增加真正覆盖风险的测试。真实调用先形成预览，不能用生产任务替代只读健康检查。

分别记录：结构/文档检查、离线测试、真实浏览器、真实 Agent Plan、同机重定位、新聊天发现和异机结果。截图来自真实运行；概念插画明确其性质，不代替功能验证。示例报告与动态展示只包含获准公开且已脱敏的内容，不分发第三方视频原件、私有提示词、账号页面或 Key。

发布按 `delivery.json` 白名单创建普通目录；新增必要文档与已验收素材同步更新清单。移除测试生成的 `__pycache__` 和任何非发布文件，不把整个工作区上传。检查中英文链接、图片原尺寸/展示尺寸、命令可复制性、许可与来源说明。采用图保留可维护源文件及简洁公开来源信息，过程记录留私有工作区。

源仓库为 [GitHub](https://github.com/HNNUYUXUAN/douyin-agent)，另提供 [GitCode](https://gitcode.com/yuxuan6426/douyin-agent)。记录实际发布提交/版本及镜像状态；未成功推送或未核对远端呈现时，不声明已上线。不要因维护文档顺带更改仓库可见性或许可证。

安装升级继续核对回执哈希并保存代码回滚副本；用户 `.env` 和工作区状态保留。原始媒体清理不可回滚。已验证能力和未验证边界在发布说明及 [验收记录](../../../references/acceptance.md) 中一致。

## 预期输出与成功依据

文档、命令、索引、发布清单和实际实现一致；测试/呈现检查各自记录。发布成功须有实际提交/推送与远端核对证据，不以本地文件存在替代。

## 停止或恢复条件

遇到秘密或未授权素材、文件冲突、测试失败或未核对的远端状态时，保留成果并停止对应发布/覆盖步骤，记录缺口；运行问题按 [恢复指南](recovery.md) 定位。
